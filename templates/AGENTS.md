# AGENTS.md template

Use one canonical repository rule file. Include only project-specific scope, risks, commands, and constraints.

- Inspect relevant files and make the smallest correct change.
- Preserve unrelated work; avoid speculative features and broad refactors.
- Never expose or commit secrets or private data.
- Use a focused branch and open a PR; do not merge.
- Run the smallest relevant check and report its exact result.
- Memory is optional and task-driven, not a default preflight.
