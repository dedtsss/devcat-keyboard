# Agent Dispatch

## Moved

Актуальный dispatch-слой перенесён в отдельный приватный репозиторий:

`dedtsss/agent-dispatch`

Эта папка оставлена только как временная историческая копия.

Общий рабочий слой для обмена задачами, статусами и отчётами между ChatGPT, Codex, Manus и другими агентами.

Цель: убрать ручную пересылку между чатами. Агент, который выполняет задачу, обязан оставлять результат здесь или в целевом репозитории и давать точную ссылку.

## Структура

```text
agent-dispatch/
  README.md
  AGENT_RULES.md
  tasks/
    YYYY-MM-DD-project-task.md
  status/
    project.md
  reports/
    project-WORK_REPORT.md
  templates/
    TASK_TEMPLATE.md
    STATUS_TEMPLATE.md
    WORK_REPORT_TEMPLATE.md
```

## Правило источника истины

Если результата нет в GitHub, для внешней проверки задача считается невыполненной.

Минимальный результат после любой задачи:

1. Код или артефакт залит в GitHub.
2. Указан точный репозиторий.
3. Указана ветка или commit.
4. Создан или обновлён отчёт.
5. В отчёте есть команды запуска, тесты, ограничения и следующие шаги.

## Как использовать

1. Новая задача фиксируется в `tasks/`.
2. Исполнитель обновляет `status/` по ходу работы.
3. После завершения исполнитель пишет итог в `reports/`.
4. Проверяющий читает GitHub, а не пересказ из чата.

## Статусы

- `planned` — задача описана, работа не начата.
- `in_progress` — работа начата.
- `blocked` — есть блокер.
- `review_ready` — результат залит и готов к проверке.
- `done` — проверено и принято.
- `failed` — задача не выполнена.

## Текущее ограничение

Этот рабочий слой временно размещён внутри `dedtsss/etalon-project-template`, потому что текущий GitHub-коннектор ChatGPT не даёт операции создания нового репозитория. Позже его можно вынести в отдельный приватный репозиторий, например `dedtsss/agent-dispatch`.
