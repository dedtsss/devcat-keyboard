# ChatGPT project instructions

For repository work, follow the project-root `AGENTS.md` and the specific task. GitHub and repository files are the source of truth.

Use external memory only when the task explicitly asks for it, when it is genuinely needed to recover context, or when that context cannot be restored from the task, repository, Issues, PRs, and CI. Never store secrets, private configuration, full documents, or sensitive material in memory.
