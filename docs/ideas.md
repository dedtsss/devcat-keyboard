# Ideas & Engineering Findings

Назначение: хранить найденные идеи, приёмы из других проектов, результаты исследований и возможные улучшения, которые ещё не являются обязательными требованиями.

Этот файл не является backlog и не является реестром принятых решений.

## Статусы

- `candidate` — стоит рассмотреть;
- `research` — требуется проверка, поиск prior art или прототип;
- `accepted` — идея принята; итог обязательно фиксируется в `docs/decisions.md` и при необходимости в GitHub Issue/spec;
- `implemented` — уже реализовано; указать Issue/PR/commit;
- `rejected` — сознательно не используем; причина обязательна.

## Правило использования

Перед крупной новой функцией, архитектурным изменением или нетривиальным workaround:

1. прочитать релевантные записи `docs/decisions.md`;
2. просмотреть этот файл, чтобы не повторять уже проведённое исследование;
3. проверить prior art: официальную документацию, upstream, Issues, PR, Discussions, changelog, forks и похожие проекты;
4. новую существенную находку записать сюда;
5. если решение принято — перенести итог в `docs/decisions.md`, не превращая `ideas.md` в скрытую спецификацию.

```text
Evidence:
Issue / PR / commit / документ при наличии
```
